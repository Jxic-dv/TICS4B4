# Proyecto de Manipulación del DOM con JavaScript

Este es un proyecto sencillo desarrollado para practicar los conceptos básicos de HTML, CSS y JavaScript, enfocado en la selección de elementos y el manejo de eventos en el DOM.

## Estructura del Proyecto

- `index.html`: Contiene la estructura básica con un título, un párrafo y un botón.
- `script.js`: Contiene la lógica de JavaScript para capturar elementos del DOM y manejar los eventos.
- `README.md`: Documentación del proyecto.

##  Funcionalidades

1. **Uso de Selectores:** Se utilizan métodos como `getElementById` y `querySelector` para capturar los elementos de la página.
2. **Eventos en JavaScript:** Al hacer clic en el botón, se ejecutan las siguientes acciones:
   - Se modifica el texto y el color del párrafo.
   - Se cambia el estilo del título.
   - Se muestra un mensaje dinámico en la pantalla.
   - Se despliega una alerta en el navegador.
